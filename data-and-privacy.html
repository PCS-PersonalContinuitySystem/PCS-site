Local storage and local AI are different

PCS keeps saved continuity in an encrypted vault on your Windows PC. That describes storage. It does not make a Google or OpenAI conversation an offline session, and it does not make cloud processing end-to-end private.

For cloud routes, conversation and enabled sharing send selected content to configured providers. Their charges and data-handling terms apply. PCS supports a separate Local conversation route for compatible Windows/NVIDIA hardware; the required model and runtime must be installed separately.

This page explains product behavior, not a security certification or a provider-retention guarantee. The app is a pre-release. Review the current release notes and the provider’s terms before using sensitive information.

What the vault covers

Saved continuity, notebooks and local plans can be inspected and revised in PCS. Encrypted backups preserve vault contents, including saved settings and remembered keys. Keep backup files protected and keep their passphrases separately. Forgotten vault passphrases cannot be recovered.

Original document files and readable exports are outside vault encryption. Keep separate copies of original Materials when making a backup. An exported Markdown or plain-text record is readable by anyone who can access that file; it is not a protected vault backup.

What can go to cloud providers

Conversation and the features you enable can share selected content: recalled context, conversation excerpts, corrections, document portions, vision input, and eligible calendar or practice requests. Memory and preparation can use separately configured provider roles. Review those choices in Settings → Connection rather than assuming one provider handles everything.

The updated memory-sharing choice can include selected original passages and current corrections. Existing users may retain a previous scope until choosing an offered update. Read the explanation for the setting actually saved in your vault.

Local storage does not prevent a selected provider from receiving permitted content. This website does not quote provider retention periods or prices because those depend on the provider and configuration and may change.

What Local mode changes

The supported Local conversation runs on the PC without an API key or cloud fallback. It can work with enabled saved continuity and supported local tools. Local vision and network research are unavailable.

For this release, the product guidance specifies the supported Gemma 4 12B QAT Q4_0 model and llama.cpp b10964 CUDA 13.3 runtime with matching libraries. Use the in-app download controls and Help for the tested files. Do not substitute an arbitrary model or runtime and assume compatibility. A general hardware compatibility guarantee and minimum RAM/VRAM figures have not been established.

English speech recognition is bundled. Spoken Local replies use an installed Microsoft David or Zira desktop voice. Listening pauses while PCS processes and speaks; transcription can be wrong, so check important requests and saved results.

What “Don’t save” means

Choose Don’t save this conversation before starting to pause new PCS saving. Earlier saved records and settings remain. The selected cloud provider still receives the conversation, and its own terms still apply.

Clear chat only clears displayed content. Hiding the memory stream only hides its panel. Neither action should be treated as deletion of saved continuity. See the memory-control guide for the differences.

Close and share deliberately

The browser address used to control PCS includes an access token. Do not post that full URL or screenshots containing it. Closing the controlling browser page stops the conversation and capture but can leave the desktop host running and the vault unlocked. Use Lock to close vault access or Quit PCS to shut the program down.

Review a generated bug report before sharing it. Reports are not uploaded automatically. Public issues and community posts are not private support channels: remove names, keys, launch tokens, personal conversations, original documents and sensitive filesystem paths.

For a cautious first trial, follow the setup guide using non-sensitive example information and turn on additional sharing only after reading its explanation.
