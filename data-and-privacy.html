PCS 0.9.50 · Storage and sharing

Know what stays here and what you share.

The encrypted vault belongs on your PC. Your connection and feature permissions determine which selected content can leave it.

On this page

Stored on your PC Cloud connections Local AI and online choices Saving and session controls Screens and support files

What the vault protects

PCS stores saved conversations, memories, notebooks, prepared reading notes, saved web snapshots and local plans in an encrypted vault. Encrypted backups preserve vault contents, including settings and API keys you chose to remember. Keep backups protected and the passphrase separately; a forgotten passphrase cannot be recovered.

Original Materials files and readable exports are outside vault encryption. Copy original documents separately when making a backup. A Markdown or TXT export is readable to anyone with access to that file and is not a complete restorable vault.

Manual reading, notebook editing, Calendar and Map browsing need no AI connection. Map connections are calculated from bounded current saved records, without a model or embedding request.

What can reach a cloud provider

Google, OpenAI and experimental Alibaba Qwen are cloud connections. Conversation and enabled features can send selected text, recalled evidence, corrections, document portions, audio or permitted images. Their API charges and data-use terms apply. Local encrypted storage does not make cloud processing local.

Review Settings → Memory & sharing and the selected provider roles under Connections. A memory or Preparation helper can differ from the conversation provider. Proactive help has its own Review model and inputs step showing its destination and permitted inputs.

Original-passage sharing is a separate choice. Saved connection profiles do not carry sharing permissions; review the offered choices when changing the model or destination.

What Local changes

Local conversation and memory use the selected model on your PC, without cloud AI fallback. Optional CPU Search by meaning also works locally; its temporary index stays in RAM and clears at Lock.

Online features still have their own destinations. Explicit Local online lookup sends queries to Brave and fetches public pages; generated queries can include details from your request. The Local model interprets the excerpts. Separately approved Materials preparation or a notebook outline may use the cloud provider displayed for that job.

Paste page text retains text you provide without a website or AI request. Explicit public-page imports contact the website. Later sharing a saved source with cloud conversation sends permitted portions under Materials controls. A pasted source is labeled as pasted; its address does not verify origin or completeness.

Saving and session controls

  • Don’t save this conversation controls new PCS saving. It does not prevent an active cloud provider from receiving the conversation.
  • Clear chat and hiding the memory stream change the display. They do not delete saved records or disable learning.
  • Stop PCS ends conversation and capture; Lock closes vault access; Quit PCS shuts down the host.

Closing the browser tab alone can leave the host running and the vault unlocked. Deleting records cannot retract earlier provider disclosure or erase older backups. See memory controls for inspection and correction.

Before sharing a screen or support file

OBS shares the scene you permit. Preview it before enabling Vision. Visible Library or Map records can appear in a shared scene; opening a local page does not protect it from screen capture.

PCS normally removes its private launch code from the browser address. A clean http://127.0.0.1:8765 address contains no code; a link containing #token= should stay private.

Bug reports are not automatically posted to support. Review the file yourself before using Discord or GitHub Issues. Remove keys, passphrases, tokens, personal records and sensitive paths.
