Before you install

PCS connects through provider APIs. Those use their own keys, access rules and billing. A consumer chat subscription does not by itself give PCS API access. A compatible local model does not need a cloud AI subscription.

No. Saving conversation text, creating memories and sharing saved information are separate settings. The model receives selected information, not your entire archive. Recall and AI-written memories can be incomplete or wrong; you can inspect and correct them.

Local conversation and memory can work offline after the required downloads. Leave online services off and check the selected providers for other tasks, such as document preparation. You can also browse saved records, read documents, edit notebooks and use the manual Calendar without starting AI.

The main download is for Windows x64. There is an experimental Ubuntu source preview with limited features. A macOS package is not included. Read the platform limits.

Use Quit PCS and wait for “PCS closed.” Closing its browser tab can leave the app running. Stop ends the conversation and capture; Lock closes access to the vault.
