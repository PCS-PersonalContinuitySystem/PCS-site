WHAT CARRIES FORWARD

More room for
the thread of an idea.

Some thoughts become questions. Some become notes, or a small plan for tomorrow. PCS gives them connected places to grow—and gives you a say in what stays.

Images show the real interface with manually authored example data, not live AI output. These captures are from PCS 0.9.8–0.9.10, as labeled; they are not new 0.9.13 screenshots.

01 Conversation

Start wherever your mind is.

Talk an idea through, ask another question, or take your time finding the words. Typed and spoken conversations have explicit session and sharing controls.

New OpenAI turn-completion choices give thinking pauses more room. The default companion direction favors a calm, capable peer and fair, evidence-backed disagreement—not constant reassurance. Model behavior and provider limits can still vary.

Actual PCS interface

The interface opens locally in your browser. Start a session, type or speak, and keep the Memory stream nearby while you talk. Optional vision uses an OBS scene you choose on supported cloud routes; OBS is a separate download.

02 Revisable memory

Keep context. Keep your say.

Inspect what was carried forward and where it came from. Correct a memory when it misses the point. Revisit it when your thinking changes.

Inspect the revision writer recorded by PCS separately from editable memory content. A provider name written inside a memory cannot override that attribution.

03 Materials and notebooks

Give your curiosity a home.

Keep original documents, topic notebooks and saved reference notes in one place. Save supported public web sources for a quiz, study session or walkthrough, then return to the captured text in later conversations.

Local documents: TXT, Markdown, unprotected EPUB and text-based PDF. Web capture: one accessible HTTPS HTML, TXT or Markdown page—not a whole website or an interactive quiz. Source text, prepared notes and your own bookmarks stay distinct.

04 Calendar and plans

Make a little room for doing.

Keep local tasks, goals and events alongside your ideas. Move through Month and Agenda views, select a date, and inspect its plans.

Choose whether PCS may assist with Calendar, then ask directly to create or edit a plan and inspect the result. No external calendar sync, bookings or reminders.

A few more ways
to follow the thread.

Map and Library help you explore recurring wording, saved memories, notebooks and the records behind them. Browse a visual map, inspect the evidence, and return to the source records that made a connection visible. Read the Map guide .

YOUR DATA, YOUR CHOICES

Personal context.
Personal control.

Your continuity belongs in a place you can inspect, revise and back up. PCS keeps its vault on your PC.

A local, encrypted vault

Saved continuity, retained notes and saved web snapshots stay in your PCS vault. Keep your passphrase safe: forgotten passphrases cannot be recovered.

Sharing you can choose

Cloud conversation and enabled sharing send selected content to configured providers. Local storage does not make cloud processing offline or end-to-end private. Requested web capture also contacts the source website.

Ways to take it with you

Create encrypted backups or readable exports. Saved web snapshots and bookmarks are included in vault backups. Original local document files need a separate copy; those files and readable exports are outside vault encryption.

Already using PCS? Update without leaving your saved information behind.

  1. 01

    Extract the portable ZIP

    Use a fresh, writable folder. Python and the application dependencies are included in the Windows package. Keep all files together.

  2. 02

    Run Start PCS.exe

    Let first-run setup prepare the bundled environment, then use the local browser interface. Create a vault or restore an existing backup and keep its passphrase safe.

    Use your own API configuration for cloud routes. For Local, download the supported model and runtime separately. Review sharing choices and begin with a short typed conversation.

English speech recognition for the supported Local route is bundled. Check important requests in the transcript and saved outcome.

Local hardware & voice details

Local conversation requires compatible Windows/NVIDIA hardware and separate supported model, runtime and CUDA-library downloads. Use the download controls in Settings and the bundled Help for the matching files; arbitrary model/runtime swaps are not supported.

Spoken Local replies use an installed Microsoft David or Zira desktop voice. Listening pauses while PCS processes and speaks; Local vision and network research are unavailable.

A Local recording ends at 30 seconds and processes the captured speech once. A warning appears around 22 seconds. A forced cutoff is partial speech, not confirmation of a complete instruction.

Read the setup guide before starting. A successful file check is not a guarantee that every hardware or background workload will fit.

PCS remains a pre-release. Offline automated checks are not a guarantee of live voice timing, successful capture from every website, or compatibility with every Windows device. Test with non-sensitive example information and keep backups.

A FEW GOOD QUESTIONS

A little clarity
before you begin.

Can PCS run offline?

Saved-record browsing and the Continuity Map work locally without loading a model. The supported Local conversation route uses your PC without an API key or cloud fallback once its separate model and runtime are installed. Compatible Windows/NVIDIA hardware is required; Local vision and network research are unavailable. Google and OpenAI conversation routes need an internet connection.

Where is my memory stored?

Saved continuity lives in your local encrypted PCS vault. Saved web snapshots and their bookmarks are also encrypted vault records, separate from personal memories. Cloud conversations and enabled sharing send selected content to your chosen provider, whose charges and data-handling terms apply. Original local document files and readable exports are outside vault encryption.

Can I change what PCS remembers?

Yes. Inspect a saved memory, its linked sources and revision history, then use the correction controls. A requested memory can be created, an existing one revised, or a verbatim note saved; check which outcome actually completed. Pending is not saved. “Don’t save this conversation” controls PCS saving; it does not undo receipt by a cloud provider.

Can I save a quiz, study guide or walkthrough for later?

Yes, when its source is a supported public page. Open Materials → Reference notes → Saved web sources → Add from web , or ask during a cloud conversation with Search and Materials sharing enabled. PCS retains the extracted source text, addresses, capture date and limitations. You can inspect it, save a bookmark or spoiler-boundary note, read portions, capture an updated version, export or delete it. A routine search does not save automatically. Saving and export are blocked in Don’t-save mode; Local mode cannot fetch outside pages.

What can the web importer capture?

One accessible public HTTPS HTML, TXT or Markdown page, up to 2 MiB downloaded and 240,000 text characters. It does not run JavaScript quizzes, crawl linked pages, extract images, import remote PDFs or bypass logins. An extracted page is not a certified complete guide or answer key. PCS reads selected portions rather than automatically putting the whole source in every prompt; already supplied passages can still accumulate in the conversation and use allowance.

What do notebooks do?

Notebooks bring together a goal, your notes, linked original documents and prepared reading notes, with up to 24 linked sources. During eligible conversations, PCS can also save separately labeled suggestions. Linking a document does not mean PCS has read all of it.

Does Calendar connect to my other accounts?

No. PCS Calendar keeps local tasks, goals and events. You can make direct requests to create or edit entries when permitted, and inspect or change them yourself. It does not synchronize Google or Outlook calendars, invite attendees, book appointments or deliver reminders.

Can I make OpenAI wait longer while I am speaking?

In Settings → OpenAI turn completion , choose patient semantic detection (the default), balanced semantic detection, or the 1.5-second silence-based fallback. The setting applies on the next Start. PCS also gives resumed speech a short settling window and yields playback when the provider detects speech. This improves the turn-taking policy; it is not a guarantee of perfect recognition or interruption-free conversation.

What does Local voice need?

English recognition is bundled. Spoken Local replies use an installed Microsoft David or Zira desktop voice alongside the supported model and runtime. Listening pauses during processing and replies. Recordings end at 30 seconds and process what was captured once, with an early warning near 22 seconds. Transcription and interpretation can be wrong; inspect important requests and saved outcomes.

What does a line in the Continuity Map mean?

Both labels occur in the same supporting current saved records. You can inspect those records and source excerpts. Dates mean last saved or edited, not last discussed. A path follows displayed links, not a causal or psychological relationship. The map is a bounded local overview; it does not reconstruct old beliefs or use a cloud model.

Why can PCS be connected but temporarily not answer?

Read the current status: Local may be processing or speaking, a connection may be renewing, or OpenAI may be waiting for allowance. Notices distinguish preventive pacing from a provider rejection and a locally selected cooldown. A preventive wait can hold one never-sent answer for up to two minutes and request it once when allowed; you do not need to repeat that question. Cancel waiting answer, Stop, Lock or changed permissions can retire it. Actual failed or cancelled requests are not automatically replayed. Provider limits still apply.

Which model wrote a memory?

The memory inspector has a “Revision writer · recorded by PCS” section. That host-recorded provider/model is separate from editable JSON, which can contain a copied or incorrect authorship claim. A writer label does not certify that the transcript or interpretation is correct.

What should I know before updating to 0.9.13?

Keep a pre-feature backup. Saving the first web source makes that vault require PCS 0.9.13 or newer, even after the source is deleted. Opening an older vault without saving a web source does not add this requirement. Encrypted backups include saved web sources and bookmarks; original local Materials files need a separate copy. Quit PCS, use a fresh extraction and follow the update and restore instructions .

Where are the guides in the download?

Start with START_HERE.md beside Start PCS.exe . Current guides are in docs , including HELP.html , which opens offline without starting PCS. Keep package files together. Use bundled Help and release notes for version-specific controls; some online guides and screenshots describe earlier builds.

Does a ChatGPT subscription cover PCS API use?

No. PCS uses your own API configuration for cloud routes. ChatGPT subscriptions and OpenAI API billing are separate . Provider rate limits can also apply while credits remain. PCS is free, with no PCS subscription or locked features; compatible Local use needs no API key.
