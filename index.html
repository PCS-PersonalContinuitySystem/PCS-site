YOUR DATA, YOUR CHOICES

Personal context.
Personal control.

Your continuity belongs in a place you can inspect, revise and back up. PCS keeps its vault on your PC.

A local, encrypted vault

Saved continuity, retained notes and saved web snapshots stay in your PCS vault. Keep your passphrase safe: forgotten passphrases cannot be recovered.

Sharing you can choose

Cloud conversation and enabled sharing send selected content to configured providers. Local storage does not make cloud processing offline or end-to-end private. Requested web capture also contacts the source website.

Ways to take it with you

Create encrypted backups or readable exports. Saved web snapshots and bookmarks are included in vault backups. Original local document files need a separate copy; those files and readable exports are outside vault encryption.

Already using PCS? Update without leaving your saved information behind.

  1. 01

    Extract the portable ZIP

    Use a fresh, writable folder. Python and the application dependencies are included in the Windows package. Keep all files together.

  2. 02

    Run Start PCS.exe

    Let first-run setup prepare the bundled environment, then use the local browser interface. Create a vault or restore an existing backup and keep its passphrase safe.

  3. 03

    Configure your conversation route

    Use your own API configuration for cloud routes. For Local, download the supported model and runtime separately. Review sharing choices and begin with a short typed conversation.

Local AI and speech assets are optional downloads. The Windows ZIP includes ordinary Python and application dependencies for offline first-run setup; it does not bundle the conversation model, runtime, Whisper, Kokoro or OBS.

Local hardware & voice details

Local conversation requires compatible Windows/NVIDIA hardware plus the selected model and matching runtime. Use Settings and Help for downloads and compatibility checks. Experimental Custom GGUF supports 8K, 16K or 32K context choices; compatibility is model- and hardware-dependent.

Use an installed Windows voice or an optional Kokoro CPU/NVIDIA voice pack. Offline English microphone recognition is a separate optional pack. Listening pauses while PCS processes and speaks; Skip speech clears current and queued Local playback without muting later replies.

A Local recording ends at 30 seconds and processes the captured speech once. A warning appears around 22 seconds. A forced cutoff is partial speech, not confirmation of a complete instruction.

Read the setup guide before starting. A successful file check is not a guarantee that every hardware or background workload will fit.

PCS remains a pre-release. Offline automated checks are not a guarantee of live voice timing, successful capture from every website, or compatibility with every Windows device. Test with non-sensitive example information and keep backups.

A FEW GOOD QUESTIONS

A little clarity
before you begin.

What does a line in the Map mean?

Both labels appear in the same supporting saved records. Select a connection to inspect those records and source excerpts. Paths follow displayed links; dates describe current records’ last saves or edits. The Map can prompt reflection, but does not establish causation or discover hidden beliefs. Read the Map guide.

Can PCS run offline?

The Library and Map work locally without a model. Local conversation and memory can run offline after the required model/runtime downloads on compatible NVIDIA hardware. Optional Local web lookup contacts Brave and requested websites; separately approved preparation may use its displayed cloud provider. Google and OpenAI conversations need internet access.

Where is my memory stored—and can I change it?

Saved continuity lives in your encrypted PCS vault. Inspect linked sources, correct a memory and compare revisions. Cloud conversations and enabled sharing still send selected content to providers. Original local Materials files and readable exports are outside vault encryption. See memory controls.

What is new for Local conversation?

Optional OBS vision, Brave web lookup, separately downloaded English recognition and Kokoro voices, plus experimental Custom GGUF model profiles. In 0.9.24, Skip speech clears current/queued playback while the conversation stays open; later replies still speak. Markdown speech cleanup leaves displayed text intact. See setup requirements.

Can I save reading material for later?

Yes. Materials brings together original documents, notebooks, prepared notes and saved public web sources. A supported web capture reads one accessible HTTPS HTML, TXT or Markdown page, not an interactive quiz or an entire site. Reading retained text is local; cloud discussion still follows sharing controls. A linked document is not a claim that PCS read it all.

Does Calendar connect to my other accounts?

Calendar keeps local tasks, goals and events with Month and Agenda views. Enable assistance separately, then inspect the result of any request. It does not sync Google or Outlook calendars, send invitations, book appointments or deliver reminders.

What does “Don’t save this conversation” do?

It pauses new PCS saving for that conversation. Earlier records and settings remain. It does not stop a selected cloud provider receiving permitted conversation content or undo prior sharing. Review the data boundaries.

What should I know before updating?

Quit PCS and preserve the earlier installation and data before using a fresh extraction. Restore a backup into an empty installation, with original Materials copied separately, or copy the entire fully stopped data folder. Never merge vaults or run two installations against one data folder. The in-app backup/restore limit is 256 MiB. Follow the update guide.

Is PCS free? Do I need a ChatGPT subscription?

PCS is free and open source under GPL-3.0-only, with no PCS subscription or locked features. Optional cloud use needs your own API configuration and may incur provider charges; a ChatGPT subscription does not supply API credits. Local use needs no cloud API key. Supporting development is optional.

Where can I find help?

Start with START_HERE.md beside Start PCS.exe, or open docs/HELP.html offline. In-app Help includes 51 searchable answers plus Research and Practice guides. For a bug, export a report, review it for private information and attach it yourself. Nothing is uploaded automatically.
