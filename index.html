Swappable cognition

Change the AI.
Keep your continuity.

The AI you use today does not have to be the AI you use tomorrow. PCS keeps your saved continuity in your encrypted vault, separate from the model that helps you think.

Move between supported Local, Google and OpenAI connections as your needs change. Your saved memories, original passages, corrections and notebooks remain available in PCS.

Your history stays with you

A provider change does not mean rebuilding your saved context from scratch. PCS can bring relevant saved evidence into later conversations, within your sharing choices and the selected model’s limits.

Choose AI for the work

Conversation, memory formation and Materials preparation have separate supported connection choices. Use the same provider or configure different helpers for those roles.

Room to change your mind

Try another supported model or a compatible Local setup while keeping the same vault. Models can differ in their responses, recall and available features; saved continuity gives you a place to continue.

Switch connections while stopped, then review the model and sharing settings before starting again. Cloud routes receive permitted content; Local routes need compatible hardware and components.

02 / Memory

Saved memories

Saving a conversation and forming a memory are separate steps. PCS keeps original passages apart from the model’s source-linked interpretations.

Library provides access to saved records, original sources and revision history. Correct a memory in your own words, or try Build my starting map for a short introduction with optional deeper questions.

Memory, sources and correction controls ↗

Saving and memory formation

Originals and interpretations

Saved passages preserve recorded wording. Memories are source-linked interpretations that can be revised. Saving & memory health shows pending work and problems.

Illustrative example

Original passage

“Liv said the river walk sounded boring, then asked where my old camera was. I don’t quite understand that.”

Source-linked interpretation

Mara is trying to understand Liv’s interest in the river and photography.

The transcript itself can contain mistakes; inspect it too.

Sources and revision history

Editing a saved memory

In Inspect, choose Incorrect, Changed, Applies in a specific context, or Forget. Preview the effect before saving your wording. Earlier accounts and their actual writers stay inspectable.

Illustrative owner correction

Too broad

“Liv dislikes river walks.”

Current corrected memory

“Liv said she likes the river. She did not want me planning her whole afternoon. She gets to choose.”

A correction is part of the current account, with history available.

Selective context for the current question

Recall permissions and context

PCS checks saved versions, permissions and required corrections before sharing selected evidence. Spoiler-limited story activities use only the complete accounts you approve. Review activity memories and reflection questions.

An example of relevant context

A later question

“Help me think of something to suggest for Sunday.”

Evidence worth bringing back

Liv likes the river and taking pictures. Borrowing the camera does not make it a shared project or a planned family outing.

Recall can miss details or choose no callback. It is not a complete account of a person.

Word search and optional search by meaning. A separate CPU model can find related wording in memories and permitted passages. Its index stays in RAM and clears at Lock.

03 / Local AI

Local AI

Local conversation and memory run on your PC using the selected model. Saved records remain in the same vault when you change providers.

The guided setup uses Gemma 4 12B. Experimental Custom GGUF support includes compatibility checks and up to eight named custom setups for model, runtime, projector, context and speech choices. Switch setups while stopped.

Recommended for Local AI: a compatible NVIDIA GPU with 16 GB of VRAM.This is a recommendation, not a minimum or a guarantee for every model and setup. Model size, context, vision and voice affect memory use. Google and OpenAI cloud connections do not require this GPU. Radeon text and Linux have separate preview limits.

Optional / Conversation

Proactive help and tutoring

Proactive offers

Proactive help is Off by default. In Settings → Conversation, choose Review model and inputs before enabling it. Screen-based offers wait during conversation activity, expire, and can be paused or dismissed.

Tutoring

Type a problem and Your current step, or review a permitted screen observation. Choose Confirm problem and step before requesting a concept hint or different practice task. Explain a full solution is a separate request.

Compatible Local models can provide this help. Typed problems need no Vision; Local screen input needs a matching projector. Exact checks cover supported arithmetic and linear equations in x. AI explanations still need review.

Storage / Permissions

Data storage and sharing

Saved conversations, memories and notebooks live in your encrypted vault. Cloud features send permitted content to the displayed provider. Original Materials and readable exports sit outside vault encryption.

Read the data and privacy guide ↗

Provider connections

Google and OpenAI use your API key. Local uses supported hardware and downloaded components. Qwen is an experimental cloud voice route with separate regional setup.

Saving and disclosure

Saving, learning and sharing are separate controls. “Don’t save” controls PCS saving; it does not undo disclosure to a provider.

Backups

Make verified encrypted backups before an update. Keep your passphrase safe; it cannot be recovered. Copy original Materials separately.

Before you start

Setup questions

What does swappable cognition mean?

You can change the supported AI model or provider while keeping the memories, corrections and notebooks saved in PCS. The vault holds your continuity; models work with selected context from it. Switching does not transfer a provider’s internal state or guarantee the same answers. See how to switch connections.

Do I need a ChatGPT or Google subscription?

PCS uses provider API access, which has its own account, billing and access terms. A consumer chat subscription does not by itself supply a PCS API key. Supported Local use does not need a cloud AI subscription.

Can I use PCS without starting AI?

Yes. Browse saved records and the Map, read Materials, edit notebooks, and use manual Calendar controls. AI conversation, research and model-generated help require an appropriate configured connection.

Is everything offline with Local?

Local conversation and memory have no cloud AI fallback. Model and component downloads need the internet. If enabled, Brave lookup sends queries and page requests online. Separately approved cloud preparation sends material to the selected provider.

Can the model be wrong about what I meant?

Yes. Transcription, summaries, recall and explanations can be mistaken. PCS gives you originals, source links, history and editable interpretations so you can inspect and correct them.

Will closing the browser stop PCS?

Closing the tab can leave the host running. Use Stop to end conversation and capture, Lock to close vault access, and Quit PCS to shut down. Wait for “PCS closed.”
