Swappable cognition

Change the AI.
Keep your continuity.

The AI you use today does not have to be the AI you use tomorrow. PCS keeps your saved continuity in your encrypted vault, separate from the model that helps you think.

Move between supported Local, Google, OpenAI and Meta connections as your needs change. Your saved memories, original passages, corrections and notebooks remain available in PCS.

Your history stays with you

A provider change does not mean rebuilding your saved context from scratch. PCS can bring relevant saved evidence into later conversations, within your sharing choices and the selected model’s limits.

Choose AI for the work

Conversation, memory formation and Materials preparation have separate supported connection choices. Use the same provider or configure different helpers for those roles.

Room to change your mind

Try another supported model or a compatible Local setup while keeping the same vault. Models can differ in their responses, recall and available features; saved continuity gives you a place to continue.

Switch connections while stopped, then review the model and sharing settings before starting again. Cloud routes receive permitted content; Local routes need compatible hardware and components.

02 / Memory

Saved memories

Saving a conversation and forming a memory are separate steps. PCS keeps original passages apart from the model’s source-linked interpretations.

Inspect original sources, correct a memory, link the steps of a decision, or keep a named lesson. Your current account and the history behind it stay distinguishable. For a place to begin, try Build my starting map for a short introduction with optional deeper questions.

03 / Local AI

Local AI

Local conversation and memory run on your PC using the selected model, with no cloud AI fallback for those paths. Saved records remain in the same vault when you change providers.

The guided setup uses Gemma 4 12B. Experimental Custom GGUF support includes compatibility checks and up to eight named custom setups for model, runtime, projector, context and speech choices. Switch setups while stopped.

Local now checks which context a question needs before replying. An available screen frame is supplied only when relevant, so personal questions can use memory without incidental desktop commentary. See how Local chooses context.

The recommended Local route uses a compatible NVIDIA GPU.The selected model, context, vision and voice affect memory use. Follow the component and compatibility checks in Settings. Google, OpenAI and Meta cloud connections do not require this GPU. Radeon text and Linux have separate preview limits.

Conversation pace and optional openings ↗

Choose the pace

Follow my lead, Think with me and Take the lead express how much initiative you want. Quiet and Stay here hold topic planning until you resume. Local has a separate experimental quiet-moment option: off by default and not restored from saved Settings, it needs Take the lead and an eligible idle Conversation page. Pending openings stop with typing, leaving the page or Stop. They cannot use tools or save themselves; preparing an idea can delay an ordinary reply. Cloud quiet openings remain unavailable.

Optional Jev selection

Jev can choose among ideas proposed by your conversation model. It starts off, needs its own TypeSafe key and a sharing review, and adds a cloud request. Local use needs separate cloud consent. Your conversation model writes the reply.

Explore saved connections

Library offers a separate Jev trial: choose a saved record, review the proposed excerpts and allow sharing for that request. Suggestions can point out relevance, repetition or possible disagreement; they do not automatically save memories or change the Map. Review the Library workflow.

Screen offers and tutoring

Proactive help is off by default. Review its model and inputs before enabling it. Exact reviewed setups can be remembered when you switch models; new combinations need their own review. Offers wait during activity, expire and can be paused or dismissed. Typed tutoring needs no Vision; confirm your problem and current step before asking for a hint or explanation.

Compatible Local models can provide this help; screen input needs a matching projector. AI replies, explanations and assessments still need review.

Storage / Permissions

Data storage and sharing

Saved conversations, memories and notebooks live in your encrypted vault. Cloud features send permitted content to the displayed provider. Original Materials and readable exports sit outside vault encryption.

Read the data and privacy guide ↗

Provider connections

Google, OpenAI and Meta use your own provider API key. Meta supports typed conversation and optional local transcription with Windows or Kokoro replies. Local uses supported hardware and downloaded components. Qwen is an experimental cloud voice route with separate regional setup.

Saving and disclosure

Saving, learning and sharing are separate controls. “Don’t save” controls PCS saving; it does not undo disclosure to a provider.

Backups

Make a checked encrypted backup before an update and copy original Materials separately. Keep its passphrase safe. New retained features can require a newer PCS reader; keep a pre-upgrade backup if you may return to an older version.

Before you start

Setup questions

What does swappable cognition mean?

You can change the supported AI model or provider while keeping the memories, corrections and notebooks saved in PCS. The vault holds your continuity; models work with selected context from it. Switching does not transfer a provider’s internal state or guarantee the same answers. See how to switch connections.

Do I need a chat subscription?

PCS uses provider API access, which has its own account, billing and access terms. A consumer chat subscription does not by itself supply a PCS API key. Supported Local use does not need a cloud AI subscription.

Can I use PCS without starting AI?

Yes. Browse saved records and the Map, read Materials, edit notebooks, and use manual Calendar controls. AI conversation, research and model-generated help require an appropriate configured connection.

Is everything offline with Local?

Local conversation and memory have no cloud AI fallback. Download components first and leave online tools off for offline conversation. Brave lookup sends public queries and page requests online. Local + Jev sends separately reviewed conversation inputs to TypeSafe; optional Library exploration has its own review for saved excerpts. Preparation and notebook outlines follow their own provider review.

Can the model be wrong about what I meant?

Yes. Transcription, summaries, recall and explanations can be mistaken. PCS gives you originals, source links, history and editable interpretations so you can inspect and correct them.

Will closing the browser stop PCS?

Closing the tab can leave the host running. Use Stop to end conversation and capture, Lock to close vault access, and Quit PCS to shut down. Wait for “PCS closed.”
