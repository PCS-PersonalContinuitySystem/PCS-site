# Review and upload the website

Read [START-HERE.txt](START-HERE.txt) for the complete steps.

## Preview

Extract the whole ZIP, then open `index.html` in your browser. Keep `assets/` and `screenshots/` beside it. No build or installation is needed.

## Publish

Upload the extracted files and folders to the root of [PCS-site](https://github.com/PCS-PersonalContinuitySystem/PCS-site), where the existing `index.html` lives. Replace matching files, preserve unrelated files and `.nojekyll`, and commit to `main`. Wait for the existing GitHub Pages deployment. Uploading only the ZIP or a new enclosing folder will not update the homepage.

This revision adds the app-matched slate and sage palette to the earlier plain-English proposal. Upload this package to get the revised colors. The application download remains PCS 0.9.114.
